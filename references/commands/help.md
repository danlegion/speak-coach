# help — command list + recommendation

List the commands in one compact block:

- `kickoff` — profile + placement (first run only)
- `drill [track]` — one drill at your level
- `warmup` — 2-minute vocal routine
- `roleplay [scenario]` — conversation drill, coach plays the scene partner
- `test` — weekly exam (due every 7 days)
- `bossfight` — monthly uncomfortable challenge
- `progress` — trend review across tracks

Then give the state-aware recommendation per the session-start protocol (test due → `test`; weak streak → re-drill; 3+ sessions without review → `progress`; otherwise the drill targeting the lowest level or the most recent un-re-drilled fix). End with: "Say the word and we start."
