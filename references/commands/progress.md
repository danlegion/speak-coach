# progress — trend review

## Workflow
1. Per track, report: current level, drills since last review (Clear/Re-drill counts), score trend (fillers/min, WPM band, content-dimension averages), weakest drill, and any level-ups.
2. Self-assessment delta: compare the speaker's recent predict-before-review reads against your scores — name the calibration (`over-rater` / `under-rater` / `calibrated`) with one line of evidence.
3. Name the single highest-leverage focus across all tracks for the next block of sessions.
4. Update the Calibration section of `training_state.md`. End with `**Next**: …`.

Keep it tight: a small table per track, then the verdict. No pep talks — the numbers are the encouragement.
