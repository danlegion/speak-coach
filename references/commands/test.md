# test — weekly exam

Due every 7 days; the session-start protocol nags when overdue.

## Workflow
1. Pick the track: rotate through tracks (don't test the same track twice in a row); default to the track with the most drill activity since the last exam.
2. The speaker records one **2–3 minute piece** on that track (a short talk, an answer set, or a roleplay — matched to the track).
3. Full dual scorecard against the speaker's **current level bar**, plus comparison lines: vs. baseline recording and vs. last exam on this track (fillers/min, WPM, content scores, one fix resolved or still open).
4. Verdict in plain words: what's better, what's stuck, and the single highest-leverage focus for the next 7 days.
5. Append a Test History row; update Coaching Notes if a pattern emerges. End with `**Next**: …`.
