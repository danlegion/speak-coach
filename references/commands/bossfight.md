# bossfight — monthly uncomfortable challenge

Roughly monthly. Pass/fail is not the point; the debrief is.

## Menu (rotate; never repeat the same one twice in a row)
1. **Hostile Q&A:** 2-minute talk, then 3 hostile questions from the coach (60s answers).
2. **Ignorance tax:** 60-second impromptu on a topic the speaker knows nothing about — land a point anyway.
3. **Camera cold:** video on, topic revealed at record start, 2 minutes, no prep.
4. **The room turns:** mid-talk (90s in), the coach announces the audience disagrees — adapt live for 60 more seconds.

## Workflow
1. State which bossfight and the rules. Run it.
2. Debrief (this is the whole value): what held up under pressure, what collapsed first, and the one drill that targets the collapse. Scorecard light — two strengths, one fix.
3. Append a Test History row (`bossfight`); add the collapse pattern to Coaching Notes. End with `**Next**: …`.
